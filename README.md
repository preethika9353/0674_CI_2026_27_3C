**Video Game  sales Analysis**

**Project Overview**

This project analyzes video game sales data using Python and Pandas. It focuses on data transformation, missing value handling, insight generation, and visualization.

**Dataset**

Dataset: Video Game Sales

Records: 16,598

Columns: 11

Format: CSV

**Tools Used**

-Python

-Pandas

-NumPy

-Matplotlib

-Seaborn

-Google Colab

**Tasks Performed**

1.Dataset selection and reading

2.Data understanding

3.Data transformation

4.Null value handling

5.Insight generation

6.Data visualization

**Visualizations**

Genre and global sales bar chart

Year vs Global_Sales scatter plot

**Conclusion**

This project demonstrates data cleaning, transformation, analysis, and visualization using Python to understand video game sales performance
